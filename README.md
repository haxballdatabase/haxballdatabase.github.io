# HaxBall Database

Primary public archive: https://haxballdatabase.github.io/

This repository is the static GitHub Pages edition of HaxBall Database, preserving competitive HaxBall history in openly crawlable HTML.

## Included

- Current HaxBall Database home page
- Player Database and 89 player entries (87 full biography sources, 2 transparent pending-profile entries)
- HaxBall Champions League Hall of Fame / main archive
- Champions League Players records page
- Champions League Teams index and 22 team profiles
- Top 25 HaxBall Players of All Time page
- Player faces, team logos, HCL winner images supplied through Edition #23, and archived Nations Cup winner images
- `sitemap.xml`, `robots.txt`, `llms.txt`, and JSON indexes

## Source handling

The site is generated from the latest MediaWiki source files and assets supplied for the HaxBall Database project. Missing biography source is not filled in from guesswork. Schurz and Vanessa currently use database-only placeholder pages.

## GitHub Pages

Deploy from the repository root on the `main` branch. Keep any existing Google Search Console verification HTML file in the repository when uploading this build.
