# HaxBall Database

A lightweight project page for **HaxBall Database**, an independent archive preserving competitive HaxBall history.

## Main links

- HaxBall Database: https://haxball-database.fandom.com/
- Top 25 HaxBall Players of All Time: https://besthaxballplayers.netlify.app/

## GitHub Pages

This repository is designed to work as a plain static GitHub Pages site.  
The main page is `index.html`.

After publishing, replace the two placeholders inside `index.html`:

- `YOUR-GITHUB-USERNAME`
- `YOUR-REPOSITORY-NAME`

with the final GitHub Pages URL values.
